# شفا AI — وب‌سایت گفتگو

این پروژه فقط وب‌سایت است و در مرورگر Chrome باز می‌شود؛ اپلیکیشن اندروید نیست.

## نیازمندی
- Node.js نسخه 18 یا بالاتر
- یک کلید OpenAI API که در تنظیمات سرور ثبت شود

## اجرای آزمایشی روی کمپیوتر/سرور
1. وابستگی‌ها: `npm install`
2. متغیرهای محیطی را تنظیم کنید: `OPENAI_API_KEY` و در صورت نیاز `OPENAI_MODEL`
3. اجرا: `npm start`
4. بازکردن: `http://localhost:3000`

## انتشار در Render
1. پروژه را در یک مخزن خصوصی یا عمومی GitHub بارگذاری کنید.
2. در Render یک Web Service از مخزن بسازید یا Blueprint را با `render.yaml` اجرا کنید.
3. متغیر محیطی `OPENAI_API_KEY` را در Render ثبت کنید؛ کلید را در فایل‌های عمومی یا GitHub قرار ندهید.
4. `OPENAI_MODEL` را مطابق مدل‌های فعال حساب API تنظیم کنید.

نکته: میزبانی رایگان به معنی رایگان بودن مصرف API نیست. سرویس رایگان ممکن است پس از بی‌کاری به خواب برود و شروع دوباره آن زمان ببرد. تاریخچه گفتگو در این نسخه فقط در حافظه همان صفحه است و حساب کاربری/ذخیره‌سازی ابری ندارد.
